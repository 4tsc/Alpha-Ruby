# Alpha Ruby

Aplicación en React Native y Expo para buscar cartas de Magic mediante Scryfall y gestionar mazos. Incluye pantallas de registro, acceso, búsqueda, detalle y edición, además de un servidor Express/MySQL de registro.

La aplicación está en [`Alpha Ruby/`](Alpha%20Ruby), dentro de la raíz de este repositorio. El backend incluido no implementa todos los endpoints esperados por el cliente y existen incompatibilidades de configuración, datos y persistencia. El estado actual y sus límites están documentados a partir del código, sin afirmar una ejecución integral validada.
